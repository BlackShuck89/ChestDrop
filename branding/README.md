# ChestDrop graphic resources

The extension's mimic-chest artwork belongs in this directory, including `mimic-mascot.png`, `icon-master-512.png`, and `reference/` mockups. Firefox-ready 16, 32, 48, 96, and 128 px icons belong in `icons/` at repository root.

`mimic-logo.svg` is a separately editable, simplified vector approximation of the approved mimic design. The complete v0.1.3 source and original PNG graphics are included in the downloadable repository import bundle.

ChestDrop is an independent extension and is not affiliated with ImgChest.
